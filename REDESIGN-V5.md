# Platform Hero Redesign V5

Rebuilt the homepage platform visual from scratch.

- Removed the old stack image and its baked-in connector lines.
- Created a native layered platform illustration in HTML/CSS.
- Added six runtime-measured SVG connectors that physically join each layer to its matching card.
- Added animated dash flow and traveling light pulses.
- Restored and strengthened hover/focus interactions.
- Hovering a capability now highlights the corresponding card, connector, endpoints, and platform layer.
- Added responsive and reduced-motion behavior.
