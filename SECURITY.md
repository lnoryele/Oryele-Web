# Security Policy

## Reporting a vulnerability

Do not open a public issue for suspected security vulnerabilities.

Use GitHub's private vulnerability reporting or Security Advisories feature for this repository. If private reporting is unavailable, contact the repository owner privately through GitHub.

Please include:

- A clear description of the issue
- The affected page, component, workflow, or dependency
- Steps to reproduce
- Potential impact
- Any suggested mitigation

Oryele will acknowledge valid reports, investigate promptly, and coordinate remediation before public disclosure.

## Supported versions

Security fixes are applied to the current production branch and any actively supported release branch.

## Sensitive information

Never commit passwords, API keys, tokens, certificates, private keys, customer data, or production environment files to this repository.
